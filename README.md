## 🚀 Быстрый запуск

### Вариант 1. Развёртывание на Vercel (Облако в 1 клик)
Проект сконфигурирован для мгновенного развёртывания на Vercel:
```bash
npx vercel --prod
```
- Статические ассеты (HTML/CSS/JS, Leaflet, Chart.js) отдаются через высокоскоростной Vercel Edge CDN.
- Серверная логика и REST API работают через Python Serverless Function (`api/index.py`).
- Полный оффлайн-fallback режим: интерфейс стабилен даже при отсутствии сетевого подключения.

### Вариант 2. Запуск через Docker
```bash
# Запуск через готовый батник (Windows)
docker-start.bat

# Или через терминал
docker compose up -d --build
```
Command Center будет доступен по адресу: `http://localhost:8080` (или `http://127.0.0.1:8080`).

### Вариант 3. Локальный запуск на Python (Zero Dependencies)
В проекте используются **исключительно модули стандартной библиотеки Python** (`http.server`, `sqlite3`, `json`, `urllib`). Никаких `pip install` не требуется:
```bash
python server.py
```

## 📊 Архитектура и REST API

| Метод | Эндпоинт | Параметры | Описание |
|---|---|---|---|
| `GET` | `/api/stats` | `?region=ru\|us` | Сводные KPI (выручка, маржа, пробег, тонно-километры, утилизация автопарка, CO2) |
| `GET` | `/api/factories` | `?region=ru\|us` | Список производственных хабов с GPS-координатами и привязанной номенклатурой |
| `GET` | `/api/routes` | `?region=ru\|us` | Топ грузовых коридоров с объёмами, координатами и средним плечом |
| `GET` | `/api/shipments` | `?region=ru\|us&page=1&limit=25` | Пагинированный реестр рейсов с фильтрацией по фабрике, ТК, типу кузова и статусу |
| `GET` | `/api/agents` | `?region=ru\|us` | Статусы 4 автономных саб-агентов, телеметрия и журнал последних решений |
| `POST` | `/api/dispatch` | `{ "region": "ru", "batch_size": 12 }` | Запуск итерации автономной диспетчеризации грузов |

## 🔒 Надежность и Безопасность
- **Автономный бандлинг вендоров**: Leaflet.js, Leaflet.css и Chart.js упакованы локально — исключены проблемы с внешними CDN, блокировками и CORS.
- **Защита от IPv6 Blackhole**: Корректная маршрутизация через IPv4 (`127.0.0.1`).
- **Транзакционность SQLite**: Режим WAL (Write-Ahead Logging) с безопасным переключением в read-only при исполнении в бессерверных средах.
